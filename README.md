# 衛教查詢系統

## 專案介紹

本專案使用 Flask 建立簡易網站後端，
進入主路由（/）後會顯示「衛教查詢系統」首頁。

---

# 使用虛擬環境（venv）

## 建立虛擬環境

```bash
py -m venv venv
```

---

## 啟動虛擬環境

```bash
.\venv\Scripts\activate
```

成功啟動後，terminal 前方會顯示：

```text
(venv)
```

---

# 安裝 Flask 套件

```bash
pip install flask
```

---

# 執行 Flask 專案

```bash
python app.py
```

---

# 開啟網站

瀏覽器輸入：

```text
http://127.0.0.1:5000
```

即可看到「衛教查詢系統」首頁。
