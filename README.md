# Flask MVP 專題

## 專題介紹

這是一個使用 Flask 建立的簡單網站。

首頁會顯示小組的期末專題主題。

---

## 建立虛擬環境

```bash
py -m venv venv
```

---

## 啟動虛擬環境

```bash
.\venv\Scripts\activate
```

---

## 安裝 Flask

```bash
pip install -r requirements.txt
```

---

## 執行 Flask 專案

```bash
python app.py
```

---

## 開啟網站

瀏覽器輸入：

```text
http://127.0.0.1:5000
```
